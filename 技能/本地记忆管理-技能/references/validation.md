# 本地记忆管理验收

## 统一只读检查

从库根执行：

```bash
python -X utf8 "技能/本地记忆管理-技能/scripts/validate_memory_knowledge_base.py" --root "." --strict
```

验证器检查核心入口、当前季度目录、UTF-8、Markdown 表格、相对链接、Skill frontmatter、项目五字段、显式项目排序、固定工作区路径和枚举前剪枝边界。机器通过不替代来源真实性、写回授权和交付质量判断。

本库已安装董事会隔离模块。只有用户明确要求维护董事会时，才额外运行：

```powershell
.\董事会\scripts\Test-BoardDirectory.ps1
```

核心 Python 验证器默认不进入董事会；专项脚本负责运行内核、系统 Agents、成员路由、12 位成员结构、原包 SHA256 与启动门禁。

## 人工验收

- 未读取或索引任务无关的运行态、缓存、依赖、历史快照、已入库原件、临时区或显式隔离模块。
- 原件和事实来源仍可回溯；姓名、日期、数据、链接和项目状态没有靠推测补齐。
- 项目状态、关键产物、下一步、项目索引和变更记录职责一致。
- Inbox 的正式写回、索引、处理件状态、移动和验收作为一个事务完成。
- README 只维护完整资产，任务路由只维护任务意图；没有产生第二套状态或规则。
- 没有写入 token、Cookie、密码、私人联系方式、登录态或浏览器 Profile。
- 生成器、脚手架模板、烟测样例和发布包在架构变化后已经同步。
- 维护董事会后已运行专项脚本；历史决策没有在未获明确记录授权时复制或写入。

无法运行检查时，报告原因、未覆盖范围和替代验证，不把部分通过表述为全库通过。
