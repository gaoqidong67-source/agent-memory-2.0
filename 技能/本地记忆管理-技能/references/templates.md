# 本地记忆模板

只在创建或整理对应类型文件时读取；不要为了形式完整机械填空。

## 稳定范式

| 对象 | 正文范式 | 权威入口 |
| --- | --- | --- |
| Inbox 处理件 | 来源与 SHA256 -> 忠实原始内容 -> 转换说明 -> 目标与状态 | [Inbox](../../../Inbox/README.md) |
| 日期笔记 | 公共元数据 -> 事件索引 -> 同名事件段落 -> 关联内容 | [日期笔记框架](../../../日常记忆/笔记框架.md) |
| 项目 README | 公共元数据 -> 五字段状态 -> 决策 -> 风险 -> 动作 -> 复盘 | [项目模板](../../../project/项目模板.md) |
| 经验教训 | 背景 -> 错误 -> 影响 -> 排查 -> 方案 -> 预防 -> 来源 | [经验教训索引](../../../经验教训/README.md) |
| 知识点 | 来源 -> 核心观点 -> 可复用方法 -> 边界 -> 转化判断 | [知识点索引](../../../知识点/README.md) |
| 判断力 | 结论 -> 适用场景 -> 决策规则 -> 边界 -> 来源 -> 状态 | [判断力索引](../../../判断力/README.md) |
| 董事会决策记录 | 决策简报 -> 参会贡献 -> 决策地图 -> 当前最优解 -> 用户最终决定 -> 验证与复盘 | [董事会决策记录](../../../董事会/决策记录/README.md) |

## 项目与日期

- 项目状态块固定包含 `当前状态`、`最后更新`、`关键产物`、`下一步`、`事实来源`。
- 活跃项目按 README 显式“最后更新”倒序稳定排列；同日保持原顺序。
- 日期笔记进入正确季度目录，索引按日期倒序且保持唯一入口。
- 新文件使用 [统一 Schema](memory-schema.md)，旧文件只随真实任务迁移。

## 放置与边界

- 工作产物、下载、脚本输出和交付物进入对应 `project/<项目名>/`。
- 日常记忆和知识点的附件正式入库后统一放在 `Inbox/已入库文件/<大分类>/`，正文只保留回链。
- 根目录不创建 `tmp/`、`output/` 或 `scratch/`。
- 董事会已作为显式隔离模块安装；普通任务仍不进入，只有用户明确启动或要求维护时才按其独立入口和专项检查处理。
