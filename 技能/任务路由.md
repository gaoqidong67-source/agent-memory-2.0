# 技能任务路由

| 任务 | 先读入口 | 边界 |
| --- | --- | --- |
| 维护 Agent Memory | [本地记忆管理](本地记忆管理-技能/SKILL.md) | 只在明确写回、维护或项目/日期资产更新时使用 |
| 换电脑或恢复能力 | [跨电脑能力复用](跨电脑Agent能力复用/README.md) | 先只读验证，不复制凭据、Profile 或登录态 |
| 选择其它 Skill | 对应 Skill | 验证当前环境、版本和固定依赖 |
| 新建、改造或归档 Skill | 技能生命周期规则 | 第三方包先审查；项目专用 Skill 留在项目内 |

需要完整技能目录、生命周期状态或批量维护时再读 [技能索引](README.md)。
