# 跨电脑 Agent 能力复用

只在当前任务依赖本地工具，且电脑、Agent 环境、盘符、授权或能力状态不明时读取。历史记录不能代替当前验证。

## 只读检查

1. 从当前库根和脚本自身位置推导路径，不假定盘符或用户名。
2. 核对操作系统、Shell、Python/Node 等必要运行时和版本。
3. 核对任务所需工具、插件、CLI 或 Skill 是否实际存在且能运行。
4. 区分“已安装”“已登录”“已授权”“当前任务可用”四种状态。
5. 报告缺口和恢复建议；未经用户确认不自动安装、登录或改变系统配置。

## 恢复边界

- 可信、许可证允许且体积合理的固定依赖可在对应工具目录保存来源、版本、SHA256、安装与验证命令。
- 不复制 token、Cookie、密码、浏览器 Profile、登录态、缓存或临时授权链接。
- 新环境重新认证；库内最多保存外部凭据或配置的引用名称，不保存秘密值。
- 工具与 Skill 互相回链，但运行时状态不写成永久能力事实。
