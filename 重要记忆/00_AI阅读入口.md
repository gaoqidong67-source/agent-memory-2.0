# AI 阅读入口

本页只保存通用偏好和任务路由；写回、安全和文件操作以根 [AGENTS](../AGENTS.md) 为准。

## 通用用户偏好

- 默认语言与表达风格：待填写。
- 正式事实必须回到源文件确认。

## 主事实入口

| 核心对象 | 主入口 |
| --- | --- |
| 记忆库结构、规则或维护 | [本地记忆管理 Skill](../技能/本地记忆管理-技能/SKILL.md) |
| Inbox 输入或整理 | [Inbox](../Inbox/README.md) |
| 项目方案、执行、状态或交付物 | [project 任务路由](../project/任务路由.md) -> 项目 README |
| 日期事实、周报或时间段汇报 | [日常记忆](../日常记忆/README.md) -> 日期笔记 |
| 用户事实和个性化表达 | [用户核心画像](01_用户核心画像.md) |
| 工具、Skill 或提示词 | 对象明确时直达具体入口；跨能力选型时读 [工具链总览](03_工具链总览.md) |
| 风险、错误、排查或外部方法 | 类别明确时直达经验/知识路由；跨领域风险时读 [02](02_经验教训和知识点索引.md) |
| 架构、品味或长期取舍 | [05](05_判断力.md) -> [判断力任务路由](../判断力/任务路由.md) |
| 仅依赖用户当前输入的通用任务 | 无需扩读 |

## 条件附加入口

- 明确写回、维护、项目存档或归档：附加本地记忆管理 Skill。
- 高风险错误、权限、路径迁移、正式外发或跨领域审查：附加 02；单一类别明确时直达主题。
- 工具尚未确定或需要组合平台、API、Skill 与提示词：附加 03；对象明确时不重复扩读。
- 需要个人事实或语气：附加 01。
- 涉及跨项目长期影响或架构取舍：附加 05。
- 用户明确说出“启动董事会决策”：读取 [董事会运行内核](../董事会/运行内核.md)，再严格按内核最小路径路由；仅提到董事会或普通分析请求不得触发。
- 引用具体项目或日期：附加对应项目 README 或日期笔记。

主入口冲突时，以最终交付物或被修改对象为主；附加入口可以有多个，但不通读全库。
