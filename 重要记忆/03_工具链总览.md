# 工具链总览

本页只在工具未确定或需要组合多种能力时读取；对象明确时直接进入具体工具、Skill、提示词或任务路由。

| 任务 | 组合路径 |
| --- | --- |
| 工具、API 或自动化 | 项目任务合同 -> [工具任务路由](../工具/任务路由.md) -> dry-run/最小样本 -> 结果回读 |
| Skill 创建或维护 | [技能任务路由](../技能/任务路由.md) -> 创建/审查 -> 验收 -> 生命周期登记 |
| 文案、视觉或正式交付 | 用户/项目事实 -> [提示词任务路由](../提示词/任务路由.md) -> 对应能力 -> 目标平台验收 |
| 工具或流程失败 | [经验教训任务路由](../经验教训/任务路由.md) -> 对应主题 |
| Agent Memory 维护 | [本地记忆管理](../技能/本地记忆管理-技能/SKILL.md) -> 源文件与索引同步 -> 健康检查 |
| 换电脑或能力恢复 | [跨电脑能力复用](../技能/跨电脑Agent能力复用/README.md) -> 只读环境验证 -> 对应工具入口 |

当前环境、版本、登录态、授权和外部 API 必须重新验证；具体命令、安装步骤和降级链只维护在对应源文件。
