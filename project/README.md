# Project 索引

本页完整索引当前活跃项目；按任务选择项目时先读 [任务路由](任务路由.md)，跨项目历史见 [变更记录](变更记录.md)，完结项目见 [已完结项目](已完结项目/README.md)。

## 索引与维护

- 每个项目按 [项目模板](项目模板.md) 建立 README，并在顶部保留公共元数据与五字段状态块。
- 活跃项目索引按项目 README 中显式“最后更新”日期倒序稳定排列；同日保持原相对顺序。
- 文件系统 mtime、深层生成物和缓存不参与业务排序；`_待添加_` 始终在最后。
- 本页只维护当前项目清单和当前状态；跨项目同步、索引调整和阶段历史只写入 `变更记录.md`。
- 只有用户明确说明项目完结时，才移入 `已完结项目/<项目名>/`；完结归类不自动创建快照。
