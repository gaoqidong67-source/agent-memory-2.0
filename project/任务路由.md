# Project 任务路由

| 任务 | 读取路径 |
| --- | --- |
| 已给出项目名或关键词 | 直接定位 `project/<项目名>/README.md`；未命中再查活跃与完结索引 |
| 继续执行、查询状态或制作交付物 | 项目 README 状态块与执行区 -> 必要的 `docs/`、`src/`、`assets/`、`output/` |
| 追溯跨项目同步或索引历史 | [变更记录](变更记录.md) -> 对应项目 README |
| 创建或推进项目 | [项目模板](项目模板.md) -> 创建/更新状态 -> 同步活跃索引 |
| 用户明确说明项目完结 | 更新状态 -> 移入 `已完结项目/` -> 同步两个索引 |
| 查看或恢复完结项目 | [已完结项目索引](已完结项目/README.md) -> 项目 README；重新推进前确认移回活跃区 |
| 存档、封存、归档或恢复 | 项目 README -> [本地记忆管理 Skill](../技能/本地记忆管理-技能/SKILL.md) |
| 创建或维护项目专用 Skill | 只读写对应项目 README 和项目内 Skill；未经用户确认不进入全局技能入口 |

既有 `archives/` 默认不读取，除非任务明确涉及恢复、校验或清理。
