# agent memory 2.0

本库保存长期记忆、项目、方法资产与复盘。Agent 先遵循 [AGENTS](AGENTS.md)，普通任务再从 [AI 阅读入口](重要记忆/00_AI阅读入口.md) 路由；本页只做全库地图。

## 入口

- [AGENTS](AGENTS.md)：自动生效的行为、安全和写回规则。
- [AI 阅读入口](重要记忆/00_AI阅读入口.md)：按任务决定下一步读哪里。
- [本地记忆管理 Skill](技能/本地记忆管理-技能/SKILL.md)：维护、整理、项目生命周期与验收。
- [跨电脑能力复用](技能/跨电脑Agent能力复用/README.md)：新电脑、新 Agent 或能力状态不明时的恢复入口。
