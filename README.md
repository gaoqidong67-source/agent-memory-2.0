# Agent Memory 2.0

面向 AI Agent 的本地长期记忆与项目知识库。本仓库保存可移植的文本结构、路由规则、Skill 和复盘方法；个人运行态、原始素材、凭据与大体积二进制只保留在本机。

Agent 先遵循 [AGENTS](AGENTS.md)，普通任务再从 [AI 阅读入口](重要记忆/00_AI阅读入口.md) 路由；本页只做全库地图。

## 入口

- [AGENTS](AGENTS.md)：自动生效的行为、安全和写回规则。
- [AI 阅读入口](重要记忆/00_AI阅读入口.md)：按任务决定下一步读哪里。
- [本地记忆管理 Skill](技能/本地记忆管理-技能/SKILL.md)：维护、整理、项目生命周期与验收。
- [跨电脑能力复用](技能/跨电脑Agent能力复用/README.md)：新电脑、新 Agent 或能力状态不明时的恢复入口。

## 仓库边界

- 进入 Git：Markdown 知识、路由、模板、校验脚本和可复用 Skill。
- 仅保留本地：`.agents/`、`.codex/`、`.obsidian/`、Inbox 原件、项目输出、大型媒体和凭据。
- `董事会/` 是本机独立维护的多 Agent 工作区，不属于本仓库的可移植快照。
- 本仓库为私有知识库；新增内容提交前应先确认不含密钥、登录态和不必要的个人原件。

## 维护与验证

```powershell
python .\技能\本地记忆管理-技能\scripts\validate_memory_knowledge_base.py --root . --strict
```

GitHub 中不包含本地 Inbox 队列、季度目录和独立董事会工作区，因此 CI 使用 `--portable --strict` 校验可移植快照。

整理内容时优先更新既有入口和索引，避免为同一事实创建多个来源；二进制交付物通过本地项目目录管理，不写入文本历史。
